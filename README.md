🧠 AI Crypto Scalper (SOL/ETH/USDT)
Автономный торговый бот, анализирующий рынок через локальную LLM (Ollama) и конвергенцию технических индикаторов.

Версия: 2.1 (Paper Trading / Binance Testnet Ready)

🚀 Архитектурные фичи:
Свободный ИИ-анализ: Бот не использует жесткие if/else правила. Локальная нейросеть анализирует конвергенцию MACD, RSI и трендов SMA.
Умный Risk-Management:
Динамический Trailing Stop (сжимает "клетку" при росте прибыли).
Механизм "Кулдаун" (блокирует торговлю на 1 час после убытка для предотвращения мести рынку).
Фильтры безопасности:
Мастер-фильтр по Bitcoin (запрет входа в альткоины при падении BTC).
Фильтр ликвидности (запрет входа при объеме ниже среднего).
Точность исполнения: Учет реального биржевого спреда при расчете точки входа.
Telegram Integration: Мгновенные пуш-уведомления о сделках и состоянии системы.
🛠️ Технический стек:
Язык: Python 3.12+
Биржа: Binance API (через CCXT)
Анализ: Pandas, TA-Lib (RSI, SMA, MACD)
ИИ Мозг: Локальная Ollama (Gemma 2 9B / Qwen 2.5)
📥 Быстрый старт:
Установите зависимости: pip install -r requirements.txt
Запустите локальную модель в Ollama: ollama run gemma2:9b
Вставьте ваш Telegram-токен в конфигурацию бота.
Запустите bot.py.
Настройки стоп-лоссов, тейк-профитов и таймфреймов настраиваются в блоке "КОНФИГУРАЦИЯ".
